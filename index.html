  • Complexity Optimization (Set Theory) For the "Common Elements in Two Lists" exercise, an initial nested loop yielded an unacceptable O(N*M) time complexity. By converting the lookup list into a Python set (hash table), I reduced lookup time to O(1), optimizing the entire function to O(N+M).
  • LIFO Stack Implementation To check for balanced parentheses, I avoided complex regex. Instead, I implemented a Stack data structure using a standard Python list, appending open brackets and popping them when a matching closing bracket appeared, effectively handling nested structures.
parenthesis_validator.py 
def is_balanced(string):
    # Mapping closing to opening brackets for O(1) lookup
    matching_bracket = {')': '(', '}': '{', ']': '['}
    stack = []

    for char in string:
        if char in matching_bracket.values():
            # It's an opening bracket, push to stack (LIFO)
            stack.append(char)
        elif char in matching_bracket.keys():
            # It's a closing bracket. Check for validity.
            if not stack or stack.pop() != matching_bracket[char]:
                return False # Stack empty or mismatch

    # Valid if stack is completely empty at the end
    return len(stack) == 0

# Edge case testing
print(is_balanced("{[()]}"))  # True
print(is_balanced("{[(])}"))  # False

# Ex 2: Finding Median with List Sorting Mechanics
def find_median(numbers):
    if not numbers: return None
    
    # Utilizing Timsort (O(N log N))
    sorted_nums = sorted(numbers) 
    n = len(sorted_nums)
    mid = n // 2
    
    # Handling even vs odd length arrays
    if n % 2 == 0:
        return (sorted_nums[mid - 1] + sorted_nums[mid]) / 2.0
    return float(sorted_nums[mid])

# Ex 8: Cumulative Sum via State Tracking
def cumulative_sum(numbers):
    # O(N) Time, O(N) Space approach
    result = []
    current_sum = 0
    for num in numbers:
        current_sum += num  # Track state to avoid nested loop O(N^2)
        result.append(current_sum)
    return result

# Ex 10: Frequency Analysis using Dictionary Hashing
def most_frequent_char(s):
    char_count = {}
    # O(N) generation of hash map
    for char in s:
        if char.isalnum(): # Filter out whitespace/punctuation
            char_count[char] = char_count.get(char, 0) + 1
            
    if not char_count: return None
    
    # Using max() with a custom key function
    return max(char_count, key=char_count.get)

Deep Dive: Algorithmic Defense

A closer look at specific logic challenges proves an understanding of underlying mechanics rather than surface-level syntax execution.

1. The Median Problem & Sorting

Before extracting the median, the array must be sorted. I utilized Python's built-in sorted() function, researching that it uses Timsort (a hybrid sorting algorithm) yielding an $O(N \log N)$ time complexity. The logic heavily relied on integer division // to correctly index the array based on whether its length was even or odd.

2. Running Sums & State Tracking

A naive approach to cumulative sums involves a nested loop to re-add previous elements $O(N^2)$. I avoided this by maintaining a current_sum state variable outside the loop. This allowed a single pass through the array, modifying the state and appending to the results array, achieving an optimal $O(N)$ time complexity.

3. Frequency Counters & Hash Maps

To find the most frequent character, relying on the .count() string method inside a loop would cause repeated string parsing. Instead, I populated a dictionary (hash map) to count occurrences in a single pass $O(N)$. I then learned to utilize the key argument in Python's max() function to return the dictionary key associated with the highest value.

Before adopting the pandas library, I utilized Python's native csv module. This manual parsing exercise highlighted the inefficiencies of row-by-row data manipulation, perfectly setting the stage for Pandas' vectorized operations.

  • Systematic Ingestion & Inspection Utilized pd.read_csv() to load raw Kaggle datasets into memory. Immediately applied df.info() and df.isna().sum() to build a topological map of missing values before attempting any modifications.
  • Targeted Null Handling Recognized that blanket dropping (dropna()) causes severe data loss. Implemented conditional cleaning: dropping rows missing critical identifiers, but utilizing fillna() with statistical means for missing quantitative data.
  • Resolving Memory Warnings Encountered the SettingWithCopyWarning. By researching the documentation, I learned the critical difference between modifying a memory "view" versus a "copy". I resolved this by enforcing explicit indexing using .loc[] for direct assignment.
